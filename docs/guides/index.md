# Guides

Each guide is the short version of one feature. The [tutorial](../tutorial/) explains the same features slowly.

| I want to | Guide |
|---|---|
| Show progress while a graph runs | [Streaming](streaming.md) |
| Wait for a person to approve something | [Human-in-the-loop](human-in-the-loop.md) |
| Run several steps at the same time | [Parallel branches](parallel-branches.md) |
| Repeat a step until the result is good | [Loops](loops.md) |
| Use a graph as one step of another graph | [Subgraphs](subgraphs.md) |
| Let an AI model do the work of a node | [AI models](ai-models.md) |
| Let a fast model pick the next step | [Decision models](decision-models.md) |
| Let an AI model call my functions | [Agents with tools](agents-with-tools.md) |
| Give an agent the tools of an MCP server | [Tools from MCP servers](mcp.md) |
| Draw a graph or test its shape | [Inspecting a graph](inspecting-a-graph.md) |
| Try a step again when it fails, or stop one that takes too long | [Retries and time limits](retries.md) |
| See what my runs did, in OpenTelemetry or my own tools | [Tracing](tracing.md) |
| Test a graph with an agent, without an API key | [Testing](testing.md) |
